# Cash page UI rework

- Reorganized the cash page into a dashboard-style layout.
- Added four neutral KPI cards: current balance, opening balance, expected balance, shift net.
- Added a compact quick-actions card for receipt, payment, refund, expense, transfer and additional operations.
- Added a dedicated shift summary panel beside the cash ledger on desktop, stacked responsively on smaller widths.
- Reduced decorative colors to the app primary accent plus neutral theme surfaces.
- Preserved all existing cash workflows and dialogs; this change is UI/layout focused.
